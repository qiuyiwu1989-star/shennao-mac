# Python 版导入器（已弃用，保留作后路）

Swift 版（`../Sources/`）已全面覆盖它的能力，日常不要用这一份。

## 为什么不删

真机蓝牙在这台开发机上受 TCC 限制——裸跑的进程调 CoreBluetooth 会直接 SIGABRT
且日志全空。Swift 版靠 `.app` 包 + `sectcreate` 嵌 Info.plist 绕过；万一签名或
权限出问题，这一份是唯一还能把录音从设备里捞出来的路。

## 用它之前必须知道的

**两套共用同一份清单**（`导入/manifest.json`）和同一套幂等键。同时跑会互相覆盖：
读—改—写之间没有锁，后写的那个会把前一个的记账抹掉——今天已经因为类似原因
出过「文件在磁盘上却被当成没下过、反复重下一整天」的事。

所以：**用它之前先退出 Swift 版的 App**。

## 已知它没有的

Swift 版后来加的这些，这一份都没有：

- 下载完整性硬闸（收到的字节必须与设备报的大小一字不差）
- 设备 3 小时上限的自动合并
- 真实录音时刻 `startedAt`
- 绕开系统代理
- 上传前定标题与项目

也就是说，用它导入的录音仍可能出现今天修掉的那几种问题。
